  1. 1

    저장소 받기

    git clone https://github.com/NawaKenny/ir-deck-skill.git
  2. 2

    스킬 폴더에 넣기

    mkdir -p ~/.claude/skills && cp -r ir-deck-skill/skills/ir-deck ~/.claude/skills/

    맥과 리눅스 기준이에요. 한 프로젝트에서만 쓰려면 그 프로젝트의 .claude/skills/에 넣으면 돼요.

  3. 3

    새 대화에서 불러 보기

아이디어만 있어요

가설이 다 맞다고 치고 12쪽을 써 본 뒤, 무엇을 실제로 재야 하는지 뽑아 줘요.

아이디어만 있는데 가설 덱 만들어 줘.

이 방식만 founder-skill이 같이 깔려 있어야 해요. 없으면 일반 만들기로 진행해요.

이 기준으로 봐요

심사역은 하루에 덱을 수십 개 읽어요. 그래서 기준이 한 가지를 겨냥해요. 제목만 훑어도 이해되고, 숫자 옆에 근거가 있을 것.

  • 제목이 결론이에요

    큰 제목은 숫자가 든 한 문장이에요. 제목만 이어 읽어도 발표가 돼요.

  • 숫자마다 꼬리표를 달아요

    출처와 계산식을 붙이고, 계산한 값은 [추정], 앞으로 이룰 값은 [목표]로 표시해요.

  • 지어내지 않아요

    자료에 없는 숫자와 고객의 말은 채우지 않고 [확인 필요]로 남겨요.

  • 약한 점을 먼저 말해요

    경쟁사가 앞서는 칸과 아직 확정되지 않은 것을 그대로 적어요.

  • 줄거리가 이어지는지 봐요

    쓰는 사람과 돈 내는 사람이 같은지 같은 고리 아홉 개를 하나씩 확인해요.

  • 꾸미는 말을 빼요

    혁신적, 압도적 같은 말 대신 줄어드는 시간과 돈을 적어요.

알고 쓰세요

정답은 아니에요

기준은 심사역이 좋게 본 자료로 전달받은 실제 IR 덱에서 뽑았어요. 지원 공고의 평가 항목이 있으면 그게 먼저예요.

모의는 증거가 아니에요

가설 덱의 모의 패널은 AI가 연기한 가상 구매자예요. 실제 고객으로 바꾸기 전에는 제출용이 아니에요.
